One line of awkward small talk that one robot says to another while they ride an elevator together. Ten candidate lines are scored against the judge's brief — elevator small talk first, then robot logic showing through, awkwardness landing, funny on first read, tightness — and the program writes the winning line to `/output/entry.txt`.

## Run it

```sh
python3 main.py
```
